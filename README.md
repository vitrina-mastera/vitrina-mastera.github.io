# Витрины мастеров

Сайты-витрины для мастеров мебели: работы, отзывы, расчёт и заявка по одной ссылке из мессенджера.
Сайт статический, публикуется через GitHub Pages.

## Что здесь лежит

| Папка | Что это |
|---|---|
| `vitriny/` | экран выбора витрины (для показа вариантов) |
| `vitrina/` | витрина мастера: лента работ, отзывы, расчёт; `redaktor/` - Мастерская; `puteshestvie/` - путешествие по дому; `dizajn/`, `dizajn2/` - оформления |
| `krasnodar/` | витрина мастера (содержимое зашифровано в `enc/`, с 2026-11-28 открыта всем: ключ в `enc/otkryto.json`); `klient/` - вход для клиентов |
| `shared/` | общие скрипты и стили: навигация, голос |
| `index.html` | корень сайта, ведёт на `vitriny/` |
| `404.html` | страница "такой страницы нет" |
| `ISTOCHNIK.txt` | из какой версии исходников собрано |

## Откуда берётся

Пока идёт переезд, это **готовая сборка**, а исходники и сборка живут в основном репозитории проекта:
`site/vitrina`, `site/vitriny`, `site/krasnodar`, `site/shared`. Обновление:

    # в основном репозитории
    python3 site/tools/vitriny-vynos.py ../ПАПКА_ЭТОГО_РЕПОЗИТОРИЯ
    # здесь
    git add -A && git commit -m "Обновление витрин" && git push

Скрипт сам проверяет, что все ссылки внутри сайта ведут на существующие файлы и что в файлах нет старого адреса.
Файлы `krasnodar/enc/`, которых нет в исходниках (например, правки мастера, опубликованные прямо сюда),
скрипт не удаляет и напоминает перенести их в исходники.

**Обновляется само**: после каждой правки витрин основной репозиторий сам собирает витрины и пушит сюда
(токеном из секрета VITRINY_TOKEN основного репо), новая версия видна через 1-2 минуты. Запасной путь -
`.github/workflows/obnovlenie-vitrin.yml` здесь (по расписанию, если GitHub его запускает).
Сразу: вкладка Actions - "Обновление витрин" - Run workflow. Из какого коммита собрано - в `ISTOCHNIK.txt`.

Руками здесь ничего не правим: следующая сборка перезапишет правку.

## Публикация (GitHub Pages)

Settings - Pages - Source: "Deploy from a branch", ветка `main`, папка `/ (root)`.
Если репозиторий называется `ИМЯ-ОРГАНИЗАЦИИ.github.io`, сайт открывается по адресу `https://ИМЯ-ОРГАНИЗАЦИИ.github.io/`,
иначе - `https://ИМЯ-ОРГАНИЗАЦИИ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Все ссылки внутри сайта относительные, работают в обоих случаях.

## Что важно знать

- Витрина Краснодара с 2026-11-28 открыта всем: ключ к зашифрованным файлам лежит рядом (`krasnodar/enc/otkryto.json`),
  пин-код не спрашивается. Чтобы снова закрыть пин-кодом - удалить этот файл в исходниках (site/krasnodar/enc/) и пересобрать.
- Черновики Мастерской хранятся в браузере мастера и привязаны к адресу сайта: на новом адресе их не видно.
  Перед сменой адреса мастер отправляет или публикует всё, что начал в Мастерской, и только потом переходит на новую ссылку.
- Страницы закрытой витрины помечены noindex - поисковики их не показывают.
