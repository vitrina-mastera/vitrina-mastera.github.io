Витрины для клиентов

Сайт для клиентов мастера: работы, отзывы и расчёт по одной ссылке из мессенджера. Две витрины - демо-версии, третья - настоящая, для мастера из Краснодара.

Клиент видит только саму витрину, без кнопок "Главная" и "Витрины" - их видите только вы. Витрина для Краснодара открыта всем по ссылке, без пин-кода.
