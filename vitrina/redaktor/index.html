Мастерская витрины

Добавляйте работы с телефона: фото сразу получают водяной знак, рассказ можно надиктовать. Всё сохраняется в этом браузере, пока вы не опубликуете.

Как выложить на сайт

  1. Проверьте черновик: так увидит клиент.
  2. Нажмите "Скачать файлы для сайта" - получится архив с текстами и фото (фото уже с водяным знаком).
  3. Отправьте архив тому, кто ведёт сайт, - он выложит его. Обычно это несколько минут.
Посмотреть как клиент

Почему не одной кнопкой: сайт лежит на бесплатном хостинге GitHub Pages, у него нет своего сервера и входа по паролю. Если захотите публиковать сами, без посредника, - это следующий шаг: подключить бесплатное хранилище с входом для мастера.

Черновик

Черновик хранится только в этом браузере. Если почистить браузер, он пропадёт - поэтому после большой правки лучше скачать файлы.
